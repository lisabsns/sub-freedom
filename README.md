# Медитация: свобода по подписке

Интерактивный лонгрид о медитации и устройстве цифровых сервисов. Две оптики — «Обещание» и «Устройство» — показывают разные прочтения одной страницы. Интерфейсы подписки и её отмены — авторские демонстрации.

## Запуск

Откройте `index.html` в браузере или запустите проект через Live Server в редакторе. Сборка и установка зависимостей не нужны.

## Структура

```text
.
├── index.html          # Содержание страницы
├── css/
│   ├── style.css       # Подключение стилей
│   ├── fonts.css       # Локальные шрифты NT Somic
│   ├── layout.css      # Оформление, сетка и компоненты
│   └── adaptive.css    # Адаптив и уменьшение движения
├── js/
│   └── main.js         # Интерактивность и прокрутка
├── images/             # Фотографии и текстура зерна
├── fonts/              # Файлы NT Somic
└── README.md
```

Все ресурсы подключены относительными путями. Для размещения нужен статический хостинг.
